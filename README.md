# Technitium-Console-Homeassistant

A Home Assistant app repository with one app: **Technitium DNS Server** with
[Technitium Console](https://github.com/byGarcia/technitium-console) as its web
interface.

## Install

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsean%2Ftechnitium_console_ha)

Or add `https://github.com/sean/technitium_console_ha` under
**Settings › Apps › App store › ⋮ › Repositories**.

See [technitium/DOCS.md](technitium/DOCS.md) for configuration.
