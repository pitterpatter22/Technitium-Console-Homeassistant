# Home Assistant App: Technitium DNS Server

Runs [Technitium DNS Server](https://technitium.com/dns/) on your Home Assistant
host, administered through [Technitium Console](https://github.com/byGarcia/technitium-console),
an alternative web console with a live dashboard, unified blocking management and
a phone-friendly layout.
